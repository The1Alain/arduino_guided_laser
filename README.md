# arduino_guided_laser
This is my second main Arduino project that I have built using servo motors, a laser pointer, a joystick and 3D printed parts. I built it as a toy for my cats and as a challenge to myself.  The laser is guided by a joystick which inputs information that is given to the two servo motors letting it go left, right, up and down.
# Information about the challenge
What is different between this and other projects I made is that I barely watched any tutorials to guide me making the code 100% mine and original (the only one I watched was to learn about the joystick). Like my other projects I also did not use AI to help me code or design the pieces.
# Difficulties
The real hardship I faced while making this project was the 3D designing. Since the code was very simple similar to a blinking led light it only took 2 to 3 hours including the time learning about the joystick. However designing the two parts placed on the servo motors took a lot of trial and error even if they seem simple. Initially, I wanted to make a piece that could stick to the servo motor similar to a head. Nevertheless, I realized that the uneven weight distribution would cause the piece to fall. So. I decided that I would make a piece that would go between the servo and the head. After a few failed attempts the piece fit perfectly finalizing my project.
